# Архивная копия сайта tenco.ru

Статическая реконструкция сайта компании «ТЭНКО» из Чебоксар по публичным снимкам Internet Archive. Содержимое представляет исторический материал: контакты, цены и ассортимент могли устареть.

Главная страница взята из [снимка 8 августа 2020 года](https://web.archive.org/web/20200808193030/http://www.tenco.ru/), который опознал владелец. Более поздняя [главная от 5 октября 2022 года](https://web.archive.org/web/20221005044154/http://www.tenco.ru/) сохранена отдельно в `home-2022.html`; сведения на ней отличаются. Страницы и ресурсы сохранились в разное время, поэтому копия не является точной резервной копией на одну дату. В [2023 году](https://web.archive.org/web/20230607081709/http://www.tenco.ru/) архив показал сообщение об истёкшей регистрации домена.

## Запуск

```sh
python3 tools/build.py
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000/. Сборка переводит внутренние ссылки в относительные пути и добавляет пометку об архивном характере сайта.

## Публикация

GitHub Actions выполняет `.github/workflows/pages.yml` при обновлении ветки `main`: он собирает `dist` и публикует результат в GitHub Pages. После создания репозитория в настройках **Settings → Pages → Build and deployment → Source** нужно выбрать **GitHub Actions**.

## Ограничения и устройство

Из 408 выбранных URL архива получены 407; CGI-ответ не удалось восстановить. Это не гарантирует сохранности всех страниц исходного сайта. Архив содержит HTML, CSS, изображения и некоторые документы, но не серверный код или базу данных. Поиск, формы и другая серверная функциональность не восстановлены. Скрипты в HTML отключены, внешние запросы и отправка форм блокируются политикой страницы. Ссылки на отсутствующие в архиве материалы могут не работать.

`site/` содержит обработанные страницы и ресурсы; `original/` — неизменённые архивные ответы двух главных страниц. `cdx-index.json` — индекс найденных снимков, `manifest.json` — результаты загрузки; записи `cached` означают, что файл уже был в папке к моменту последнего запуска и его точная дата не зафиксирована этим запуском. `tools/restore.py` загружает выбранные ресурсы из Wayback Machine.
